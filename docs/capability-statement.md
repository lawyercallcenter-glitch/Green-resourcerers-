# Capability Statement — The Green Resourcerers LLC

## Core Competencies

- **Satellite dish removal** — safe extraction from rooftop, ground-mount, and attic installations
- **Precious metal recovery** — copper, aluminum, and rare earth element separation
- **Environmental recycling** — certified e-waste processing in compliance with EPA and state guidelines
- **Homeowner outreach** — community engagement, free removal service, property value enhancement
